# مرسم دمشق الرقمي (Damascus Digital Studio)
## دليل الإعداد والنشر (SVU-F25 — CMWeb)

هذا الدليل يشرح كيفية تشغيل المتجر محلياً، تثبيت حزمة OpenCart 4.0.2.3، استيراد البيانات التجريبية، تفعيل الإضافة، واختبار الميزات المطلوبة (منتجات رقمية قابلة للتحميل، PayPal تجريبي، التسويق/الحلفاء، التقارير)، مع توثيق حالة الاستضافة الفعلية.

> **حالة الاستضافة الحالية (موثّقة بصدق):** النطاق `damascus-digital.infinityfreeapp.com` يُحلّ عبر DNS إلى `185.27.134.24`، لكن صفحة InfinityFree تُظهر خطأ **"DNS Resolution Error / Domain Not Found"** لأن النطاق غير مربوط بحساب استضافة فعّال. **الموقع غير منشور على الإنترنت حالياً.** السكربت `3_Deploy_To_CMWeb\Deploy_To_CMWeb.ps1` يتحقق من هذه الحالة ويخرج برمز خطأ غير صفري حتى ينجح النشر الحقيقي.

## 2) المتطلبات

- OpenCart **4.0.2.3** (أحدث من 4.0.0.0).
- PHP 8.1/8.2 مع امتدادات OpenCart الاعتيادية (mysqli, gd, curl, zip, mbstring، إلخ).
- MySQL/MariaDB.
- متصفح حديث لواجهة العرض؛ ويمكن تشغيل خادم PHP مدمج محلياً للاختبار.

> ملاحظة: تم التحقق من الحزمة محلياً باستخدام PHP 8.2 وMariaDB 10.11 (منفذ 3316، قاعدة `opencart`، بادئة `oc_`).

## 3) تشغيل واجهة العرض (Storefront Demo) محلياً

1. افتح الطرفية داخل `1_Runnable_Storefront_WebApp`.
2. شغّل خادماً بسيطاً (أو افتح `index.html` مباشرة عبر `file://`):
   ```powershell
   python -m http.server 8817
   ```
3. افتح: `http://127.0.0.1:8817/index.html`
4. جرّب: التبديل AR/EN و USD/SYP، إضافة منتجات للسلة، تطبيق كوبون `DAMASCUS20` (على سلة ≥ 10$)، إتمام الدفع عبر **PayPal Sandbox** (موافقة/إلغاء) أو تحويل بنكي (Pending)، تنزيل الملفات من "تنزيلاتي" بعد اكتمال الطلب، إنشاء رابط تتبع حليف `?tracking=...` ومشاركته، إرسال تذكرة خدمة عملاء، ومراجعة لوحة الإدارة/التقارير (الزيارات والمصادر والأرقام محسوبة من الحالة الفعلية).

لإعادة الضبط: زر "إعادة ضبط بيانات العرض" في لوحة الإدارة (يمسح حالة `dds_store_v2`).

## 4) تثبيت OpenCart 4.0.2.3 (ملخص)

1. أنشئ قاعدة بيانات فارغة (مثلاً `opencart`، ترميز `utf8mb4`).
2. ارفع ملفات OpenCart 4.0.2.3 إلى مجلد الويب وشغّل معالج التثبيت، أو استخدم CLI:
   ```bash
   php install/cli_install.php install \
     --db_hostname 127.0.0.1 --db_username root --db_password "" \
     --db_database opencart --db_port 3306 --db_prefix oc_ \
     --username admin --password "<كلمة_مرور_قوية>" \
     --email admin@example.com --http_server "http://127.0.0.1:8080/"
   ```
   (غيّر المنفذ/المسارات/بيانات الاعتماد حسب بيئتك. **لا تستخدم كلمات مرور ضعيفة في بيئة عامة.**)
3. احذف مجلد `install/` بعد التثبيت وأمّن مجلد الإدارة.

> ملاحظة تقنية: بدون قواعد إعادة كتابة (`.htaccess`/SEO URL) تبقى الروابط بالشكل `index.php?route=...` وهذا متوقع؛ تفعيل SEO URL اختياري.

## 5) رفع الأصول واستيراد البيانات (Seed)

1. **ارفع الأصول المطابقة قبل/أثناء الاستيراد** (موجودة جاهزة في `2_OpenCart4_Server_Package/upload/`):
   - انسخ محتوى `upload/image/catalog/damascus/` إلى `<opencart>/image/catalog/damascus/` (6 صور PNG).
   - انسخ محتوى `upload/system/storage/download/` إلى `<opencart>/system/storage/download/` (6 ملفات: 4 SVG و2 DXF).
   (بدونها لن تظهر صور المنتجات/روابط التنزيل بشكل صحيح.)
2. **استورد البذر** `damascus_digital_store_seed.sql` عبر phpMyAdmin أو:
   ```bash
   mysql -u root -p opencart < 2_OpenCart4_Server_Package/damascus_digital_store_seed.sql
   ```
   - البادئة `oc_`. السكربت **آمن لإعادة التشغيل** (يحذف صفوفه أولاً ولا يستخدم `ON DUPLICATE KEY`).
   - ينشئ: 3 تصنيفات، 6 منتجات قابلة للتحميل، 6 تنزيلات، 4 طلبات (حالتان Complete، واحدة Pending، واحدة Canceled)، 3 عملاء، 5 مصادر تسويق، كوبون `DAMASCUS20`، حساب حليف `DDS-AFF-1001` (عمولة 10%)، عملة SYP (13000)، وصفحات معلومات وسياسات ثنائية اللغة، وإعدادات المتجر (بدون شحن/ضريبة للمنتجات الرقمية).

**بيانات تجريبية (للاختبار المحلي فقط):** العملاء التجريبيون بكلمات مرور تجريبية مضمنة في البذر (انظر ملف SQL) — غيّرها/احذفها قبل أي نشر عام. حساب مدير OpenCart هو الذي أنشأته أنت أثناء التثبيت.

## 6) تثبيت الإضافة (Damascus Competitive Pack)

الإضافة وحدة حقيقية (`module`) تضيف مشاركة اجتماعية، رابط تتبع حليف `?tracking=CODE`، وعلامة مائية للمعاينة.

1. من لوحة الإدارة: **Extensions → Installer** وارفع `2_OpenCart4_Server_Package/damascus_competitive_pack.ocmod.zip` ثم أكمل التثبيت.
2. اذهب إلى **Extensions → Extensions → Modules** وابحث عن **"Product Share, Affiliate Link & Preview Watermark"** واضغط **Install (+)**.
   - عند التثبيت تُنشأ نسخة وحدة وتُسند تلقائياً إلى تخطيط **Product** (`content_bottom`) وتُكتشف شفرة تتبع حليف مفعّل إن وجدت.
3. (اختياري) **Edit** لضبط الاسم، كود الحليف (مثلاً `DDS-AFF-1001`)، الشبكات، والعلامة المائية ثم **Save**.
4. تحقق من صفحة منتج: يظهر صندوق `dds-share` مع روابط واتساب/تيليجرام/فيسبوك/إكس/لينكدإن/بريد ورابط حليف يحتوي `tracking=...` وعلامة معاينة.

> إضافة كاملة حليف/عمولات في OpenCart موجودة مسبقاً (`config_affiliate_status` مفعّل، عمولة 5% افتراضياً في الإعدادات العامة؛ سجل الحليف التجريبي بعمولة 10%). مسار التسويق: **Marketing → Marketing / Affiliates** والتقارير من **Reports**.

## 7) الاختبارات والتحقق

- **الواجهة:** تصفح الكتالوج، فلترة/بحث، USD↔SYP، كوبون بحد أدنى، دفع PayPal محاكاة (approve/cancel)، بنك (pending) ثم اعتماد الطلب من لوحة الإدارة، تنزيل ملف لكل بند طلب مع عدّاد متبقٍ، رابط `?tracking=` يزيد إحالات الحليف والزيارات، تذكرة دعم، تقارير محسوبة.
- **OpenCart (بعد الاستيراد):** المتجر يعرض 6 منتجات/3 تصنيفات، الطلبات 1001–1004 بالحالات الصحيحة، تقارير التسويق/المبيعات/المشاهدات، وصفحات السياسات، والتنزيلات المرتبطة.
- **النشر:** 
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\3_Deploy_To_CMWeb\Deploy_To_CMWeb.ps1 -Verify
  ```
  يخرج **1** حالياً لأن النطاق غير منشور (سلوك مقصود وصادق). للنشر الحقيقي وفّر استضافة مهيأة وبيانات FTP/FTPS ثم:
  ```powershell
  .\Deploy_To_CMWeb.ps1 -Deploy -FtpHost <host> -FtpUser <user> -FtpPassword <secret> -RemotePath /htdocs -UseSsl
  ```

## 8) ملاحظات الأمان والنزاهة

- لا تُضمّن بيانات اعتماد حقيقية في المستودع/التقرير؛ أي سرّ يُكشف يجب اعتباره مُخترقاً وتدويره.
- لا يمكن اختبار PayPal الحقيقي End-to-End دون حساب/بيانات Sandbox من PayPal — الواجهة توفر محاكاة sandbox approve/cancel، وOpenCart يدعم تهيئة بوابة PayPal عند توفر البيانات.
- حالة الاستضافة مُبلّغ عنها بصدق (النطاق غير مربوط بحساب استضافة بعد)؛ لا تدّعِ أن الموقع حيّ دون تحقق فعلي. في هذه البيئة تم تجنب تسجيل الدخول إلى استضافة طرف ثالث ببيانات غير مملوكة/مؤكدة.
- حزمة اللغة العربية الكاملة (`ar-sy`) غير مضافة كصف لغة لتجنب كسر الكتالوج لغياب ملفاتها؛ المحتوى ثنائي اللغة مُقدّم في الحقول والوصف والواجهة.
